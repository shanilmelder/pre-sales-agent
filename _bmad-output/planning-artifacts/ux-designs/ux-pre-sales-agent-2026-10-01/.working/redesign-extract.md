# Redesign extract: presales-agent-design-spec-standalone.html

Source: `imports/presales-agent-design-spec-standalone.html` (625 KB). Working note only; no spine file was edited. The HTML was decoded (gzip/base64 manifest, template, JS) in the scratchpad; fonts and React/runtime blobs were skipped. Persona names and emails in the demo data are replaced by roles here (organisation rule: no personal identifiers).

Note on colours: the HTML's CSS custom properties are the source of truth below. Where the HTML says `primary-x` it means the "primary used as text/icon colour".

## 1. Overview

**What it is.** A single-page interactive "design spec" (React + a "dc" runtime, titled "Presales Agent · design spec"). It is one fixed **1440 x 900 app frame** (radius 12, shadow `0 8px 30px rgba(0,0,0,.12)`, page `min-width:1440px`) showing a fully clickable prototype, plus a **component sheet** below it (Status pill, Evidence chip and agent content, Type/space/shape). A header strip carries harness toggles: `Blockers: 8|0`, `State: normal|loading|empty|conflict|denied`, `Live: Reconnecting|Connected`, `Density: comfortable|compact`, `Theme: light|dark`. These are spec-viewer controls, not product UI.

**Screens (all in one frame):** Inbox, My Opportunities, All Opportunities (list), New Opportunity, Opportunity workspace with 9 tabs (Overview, Sources, Requirements, Gaps, Assessments, Conflicts, Estimate, Trace, Actuals), Knowledge (4 sub-tabs incl. a **Graph**), Reports (3 sub-tabs), Admin (4 sub-tabs). Overlays: Command palette, Keyboard shortcuts, Set Baseline dialog, Cancel run dialog. Right pane (420px): Inspector or Activity.

**Demo data:** one Opportunity ("Riverside DC automation", a warehouse/WMS automation deal: SAP EWM integration, CRM migration, SSO, picking), v3 draft Estimate 278.0 h, 8 blockers (3 Gaps, 2 Conflicts, 1 uncovered Requirement, 2 unaccepted Assumptions) + 2 "to Baseline". Run 2 stopped at the token limit.

**Design intent (inferred).** A friendlier, more "dashboard-like" workspace than the Linear-style spine: bigger type (14px body), roomier padding, white cards with borders plus a subtle shadow, tinted status pills with icons, KPI tiles, a visual submission pipeline, agent reasoning shown inline, a Knowledge graph, and role-based Reports (variance, pipeline, cost). It keeps the glossary (Gap, Conflict, Assumption, Condition/Contingency, Baseline, Evidence, Trace) and the "blockers to submit / blockers to Baseline" gate model. It also reflects the repo's real stories (Knowledge `Embedding` / `Embedding failed`, local models via Ollama, token budget, 50 MB upload limit).

No author annotations/comments exist beyond the component-sheet captions (quoted in section 3.14).

**At risk / failing:**
1. **Global anchor colour `a{color:#4F5BD5}` in dark theme: 3.00:1 on surface `#1B1E27` (3.26 on bg `#14161D`)** fails 4.5:1 for text.
