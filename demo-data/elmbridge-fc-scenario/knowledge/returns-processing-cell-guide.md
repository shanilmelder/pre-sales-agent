# Returns processing cell guide

Internal delivery knowledge, version 1, reviewed August 2026. Owner: Warehouse solutions practice.

## When this applies

E-commerce fulfilment sites that put returned items back into automated storage: returns
benches, grading, refurbishment routing and re-induction to an AS/RS.

## Typical effort (hours)

| Item | Low | Typical | High |
|------|-----|---------|------|
| Returns bench (hardware install and commissioning), per bench | 16 | 24 | 36 |
| Returns grading workflow in the WMS (A/B/C) | 60 | 90 | 140 |
| Re-induction of A-grade items to the AS/RS | 30 | 50 | 80 |
| Returns authorisation feed from the ERP | 40 | 60 | 100 |
| Training, per shift | 8 | 12 | 16 |

## Lessons learned

- Returns volumes peak in January at about twice the yearly average; size benches for it.
- Customers almost always decide late whether returns are in scope; carry returns as a
  Condition until the decision is written down.
- Grade C (dispose) items need a cage and a disposal record for the waste carrier.

## Mandatory checks before estimating

- Returns in this phase or the next (written decision).
- Daily returns volume and January peak.
- Number of benches and their location relative to the AS/RS inbound.
- Who issues returns authorisations (ERP, marketplace, or both).
