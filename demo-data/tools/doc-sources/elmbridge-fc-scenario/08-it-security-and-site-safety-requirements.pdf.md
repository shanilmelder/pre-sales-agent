# Harbourline Home & Garden - IT Security and Site Safety Requirements for Suppliers

Appendix B to the Elmbridge FC tender. Mandatory for the supplier and its subcontractors.

## IT security

- Single sign-on for all user-facing software. Harbourline is moving from Okta to Microsoft Entra ID; the supplier must support both (SAML 2.0 or OIDC).
- Multi-factor authentication for all remote and administrative access.
- Remote support only through Harbourline's vendor access gateway, with named accounts. New accounts take about three weeks.
- Automation network separated from the office network by a firewall. Harbourline decides whether the automation gets a dedicated VLAN.
- Supplier software patched quarterly; critical vulnerabilities within 30 days.
- Cyber Essentials Plus or ISO 27001 certification for the supplier.

## Data

- Customer personal data (names and addresses on labels) is processed only for despatch and deleted from the WMS after 90 days.
- Backups of the WMS database daily, kept 35 days, stored in the UK.

## Site safety

- All installation work under a construction phase plan; the supplier is principal contractor for the automation area.
- Work at height on the mezzanine and racking only with a permit.
- Fire strategy: the fire authority reviews the final design before approving the sprinkler layout. Any extra in-rack sprinklers it demands are the supplier's to install.
- Hot works permits issued by Harbourline facilities, 48 hours' notice.
- Site induction for every engineer; allow half a day per person.
